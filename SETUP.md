# TipTap — Настройка на бекенда (Supabase)

Това ръководство описва как да свържеш приложението с реална база данни.
Докато не добавиш ключовете, сайтът продължава да работи като демо (данните се
пазят само в браузъра).

## 1. Създай Supabase проект
1. Влез в <https://supabase.com> и създай безплатен проект.
2. Избери регион **Central EU (Frankfurt)** (най-близо до България).
3. Запомни паролата на базата (трябва ти само при директен достъп).

## 2. Пусни схемата на базата
1. В Supabase отвори **SQL Editor → New query**.
2. Копирай цялото съдържание на [`supabase/migrations/0001_initial_schema.sql`](supabase/migrations/0001_initial_schema.sql)
   и го изпълни (**Run**).
3. Готово — таблиците, правилата за достъп (RLS) и функциите са създадени.

## 3. Вземи ключовете
Supabase dashboard → **Project Settings → API**:
- **Project URL** → `VITE_SUPABASE_URL`
- **anon public** ключ → `VITE_SUPABASE_ANON_KEY`

## 4. Добави ги локално
1. Копирай `.env.example` като `.env.local`.
2. Попълни двете стойности.
3. Рестартирай dev сървъра (`npm run dev`).

`.env.local` е в `.gitignore` — ключовете никога не влизат в Git. (`anon`
ключът е публичен по дизайн; защитата идва от RLS правилата в базата.)

## 5. За живия сайт (по-късно)
Когато минем към Vercel, същите две променливи се задават в
**Vercel → Project → Settings → Environment Variables**.

---

### Какво следва
След като базата е вдигната, свързвам:
1. реалния поток на оценяване (сканиране → оценка → запис в базата → Google 5★
   пренасочване / частна обратна връзка към управителя),
2. реалния вход за управители (Supabase Auth),
3. формата за контакт да записва запитванията в базата.
